# 角色设定集画面组织目录

先选择页面组织，再选择边框语言与环境。所有模板都要求正面、45°侧前、正侧面和背面四个完整转面，但不必把它们做成四块等权格子。取景范围由主技能中的 F1（带肩头像）、F2（身体服饰）或 F3（全身像）统一控制。

## R1｜标准转面板

**适合**：需要后续出不同场景、服装或动作的角色；强调身份、体态与服装结构。

**画面组织片段**：横向设定集页面，四个等宽的完整人物转面自左至右排列为正面、45°侧前、正侧面、背面。人物取景范围依 F1/F2/F3 保持一致，画面边缘有干净留白，转面之间由细微视觉节奏而非粗重线框区隔。无局部特写；四个视图均为同等信息优先级。

**环境默认**：低对比工作室空气、极淡无叙事渐变。

## R2｜角色设定集主视觉页

**适合**：游戏角色集、立绘设定页、人物气质与服装细节都需要被展示。

**画面组织片段**：横向高级游戏设定集页面。正面视图占主视觉区；45°侧前、正侧面与背面以较小但完整可读的同档取景转面组成一列或一组，围绕主视图形成清楚阅读顺序。仅在一处加入发饰、领口、腰封或袖口的精致局部细节群；保留足够安静留白，不把每个区域塞满。四个转面必须遵守所选 F1/F2/F3 的统一裁切范围。

**环境默认**：低对比、与角色主色相容的色场，环境只作为纸外空气层。

## R3｜世界观角色图鉴

**适合**：宗门人物、幻想世界角色、需要让身份与所属环境同时成立的设定页。

**画面组织片段**：横向世界观角色图鉴。正面视图作为最大主视觉；45°侧前、正侧面与背面沿一侧或下方形成节奏清楚的辅助信息组。环境只在最远背景与外缘给出一个可读但概括的世界观锚点，例如宗门门阙、雪峰、云海、塔楼、古树、船舷或城市天际线。允许一个小型器物、徽记结构或服装细节群作为次要信息，但它不遮挡任何转面，不与人物主视图抢焦点。

**环境默认**：与角色叙事匹配的低对比空间，远景保持可辨轮廓而非整体雾化。

## R4｜仪式与职业档案页

**适合**：圣女、祭司、骑士、学者、门派核心人物等有明确身份与礼装逻辑的角色。

**画面组织片段**：横向正式档案式设定集页面。正面与45°侧前视图构成主信息组；正侧面与背面保持完整、略小但轮廓清晰。围绕人物使用克制的结构化留白、对称或半对称秩序、一个身份相关的材质或器物细节群。重点是服装层次、身份标志与仪式感，禁止做成办公 UI、表格或带文字的证件页。

**环境默认**：稳定、安静、秩序感强的低对比色场。

## 环境与设定集氛围

将下列片段附加到所选页面组织后。它们描述的是画面内环境，不是摄影背景布或贴图。

| 名称 | 环境片段 | 最适合 |
| --- | --- | --- |
| 中性空气 | 干净浅中性色场、细腻空气透视、柔和均匀光线，无具体地点。 | R1、所有角色。 |
| 玉牍静室 | 青白与玉灰色场、极淡卷轴纸感与抽象殿宇秩序，安静档案气氛，无文字。 | 东方式门派、学者、仪式职业。 |
| 雪境宫阙 | 冰白、雾蓝与极少暖金，远处只保留雪峰和宫檐的概括轮廓，空气冷而通透。 | 冰雪仙侠、圣女、北境角色。 |
| 云海天台 | 低对比云海、远处天光、克制的浮岛或石台剪影，空间开阔而不空洞。 | 仙侠、神话、高空世界。 |
| 月影秘藏 | 深青灰到月白的层次、极淡月轮和石质拱券轮廓，人物主视觉仍保持明亮。 | 秘术、夜行、暗色奇幻。 |
| 纸本博物 | 明亮米白纸感、浅墨灰边缘、极轻印刷颗粒，不做旧、不脏、不把纸纹铺满人物。 | 古典、历史、博物志风格。 |

## 选择规则

1. 用户已选定画风时，先匹配画风再选择边框；不让环境名称代替材质、光线和画面组织。
2. 用户说“设定集”但没指定用途时，默认 `R2 + 与画风匹配的边框 + 中性空气`。
3. 用户说“可供后续出图的标准四视图”时，默认 `R1 + 与画风匹配的极简边框 + 中性空气`。
4. 用户指定宗门、城市、学校、军团等世界观归属时，优先 `R3` 或 `R4`，环境只给出一个叙事锚点。
5. 不在图中生成文字、角色名字、页码、标志、UI、参数表、坐标线或水印；“设定集感”来自构图、层级、边框语言、细节群和留白。
