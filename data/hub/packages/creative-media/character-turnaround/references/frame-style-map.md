# 与画风匹配的边框语言

边框是设定集插画的一部分，不是独立的海报框、UI 组件、贴纸或外部模板。先从参考图或 Style lock 判断画风，再采用匹配的边框片段。未指定时选“画风内生极简边框”。

| 边框语言 | 匹配画风 | 边框片段 |
| --- | --- | --- |
| 画风内生极简边框 | 不确定画风，或希望最大兼容性 | 以当前画风已有的线条粗细、明暗层级和色彩关系，在外缘和信息分区加入极少量细线、浅色块与留白；边框像画面自然生长出来的秩序，不显得另贴一层。 |
| 清透二次元原画边框 | 精美二次元、商业游戏原画、清晰 CG 插画 | 细而准确的冷灰蓝或主色同系轮廓线、半透明色块分区、局部克制暖金高光；边缘干净、几何秩序明确，避免厚重金属、浮雕、UI 图标和过密花纹。 |
| 半写实概念绘画边框 | 半写实数字幻想、精修概念图 | 平滑且低对比的材质色块、选择性硬边与轻微空气过渡构成分区；边框服从画面明暗，不使用漫画线、工程网格或满版纸纹。 |
| 水墨与纸本边框 | 数字水墨、古典山水、纸本手绘 | 留白、极淡纸色、局部细线描与边缘轻微墨色收束；湿墨与纸纹只停留在外缘和最远空气层，主视图和转面轮廓保持干净。 |
| 钢笔与图鉴边框 | 钢笔线稿、排线、图形化幻想插画 | 深靛或黑色线框、稀疏分级排线、小范围装饰结构；线密度从人物主视觉向外下降，不能把整页变成同等复杂的线稿噪点。 |
| 华丽仪式边框 | 礼装、神职、皇室、强装饰幻想 | 与服装中一种已有材质呼应的局部纹样、窄金属边、宝石或云纹结构；装饰集中在外缘和一个身份细节群，禁止满页金边、重复徽记或无意义花饰。 |

## 不匹配组合

- 清透二次元人物不要套脏旧纸张、厚重油画框或摄影胶片边。
- 水墨人物不要套镜面金属 UI、荧光网格或平滑 3D 卡片。
- 钢笔图鉴不要用大面积柔焦光晕替代线条分区。
- 任何画风都不要使用可读文字、数字、参数框、角标、Logo、水印或真实应用界面。

## 边框使用准则

1. 先确定主视图、辅助转面和静区，再添加边框；边框不能承担画面主体。
2. 边框的最强对比不得超过人物脸、服装轮廓或关键细节。
3. 边框不能跨越角色的眼睛、手、鞋履、发饰和衣摆，不要把人物裁成卡片头像。
4. 角色参考已有强烈风格时，只提取其可迁移的线条、边缘、光色和材质逻辑；不得复制参考图的背景、建筑、姿势或构图。
