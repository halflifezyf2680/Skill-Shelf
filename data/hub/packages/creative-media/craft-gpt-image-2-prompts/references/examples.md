# Sparse-input examples

These examples demonstrate decision quality and output shape. Do not copy their aesthetics into unrelated requests.

## Sparse character request

User input:

`少女、雨夜便利店、孤独、电影感`

Good response:

**创作方向** — 把“孤独”落实为深夜购物后的短暂停留：人物不是摆拍，而是在便利店冷光与街道雨幕的边界上走神。

**最终提示词**

```text
创作一张写实电影剧照感的人物叙事图。

场景与瞬间：深夜的街角便利店，刚下过一阵大雨。一名约二十岁的年轻女子独自站在店外狭窄的遮雨棚下，手里松松握着一袋刚买的日用品，正看着马路对面的空公交站走神；她不是看向镜头。湿漉漉的人行道反射店内冷白荧光和远处模糊的红色尾灯，玻璃门上有雨滴、指纹和零散的室内倒影。

人物：略显疲惫的圆长脸，眉眼自然不对称，眼下有轻微倦色，黑色短发被湿气打乱，几缕头发贴在脸侧。穿洗旧的深灰色连帽外套和普通帆布鞋，衣料边缘带少量雨水，姿态略微收肩，重心落在一条腿上，另一只手插在口袋里。保留真实皮肤纹理和自然比例，不做精致妆容或时尚摆拍。

构图：竖幅中景，人物位于画面右侧三分之一，左侧保留通向空公交站的大块雨夜负空间；视点接近人眼高度，便利店门框形成轻微框景，前景有失焦雨滴，背景车辆和招牌只作为模糊色块。画面首先读到孤立的人物轮廓，其次才读到空旷街道。

光线与色彩：便利店的冷白光从侧后方勾出湿发和肩线，街道以深蓝灰为主，远处只有克制的暗红反光；真实低照度曝光，阴影中保留细节，不使用夸张霓虹、强烈橙蓝调色或戏剧性轮廓光。

媒介与质感：photorealistic，像真实摄影机捕捉到的安静瞬间；轻微高感颗粒、湿地和玻璃的可信反射、自然景深，整体克制、生活化、未经造型。

约束：人物双手关系清楚、身体比例自然；不出现文字水印、品牌特写、额外人物或直视镜头的姿势。
```

## Precise reference edit

User input:

`图1人物换上图2的红色夹克，脸和背景都别变`

Good response:

**创作方向** — 只进行服装替换，并把图2夹克的版型与材质自然适配图1人物现有姿势。

**最终提示词**

```text
编辑所提供的图片。

参考分工：图1是基础人物、姿势、构图和场景；图2只提供红色夹克的设计、颜色、面料和细节。

只改变：将图1人物当前的上衣替换为图2中的红色夹克。保持夹克的领型、拉链、口袋、缝线、红色色相和面料质感，并按照图1人物的身体比例与现有姿势自然贴合。袖口、肩部、肘部和腰部应出现符合姿势的褶皱与张力。

必须原样保留：图1人物的脸、五官、肤色、表情、发型、身份特征、身体轮廓、姿势、手部位置、相机角度、裁切、背景、景深和整体色调。

融合要求：夹克的受光方向、亮度、色温、阴影、遮挡关系和边缘清晰度必须匹配图1；让服装像拍摄当时真实穿在人物身上，而不是后期粘贴。

不要添加首饰、文字、标志或其他服装；不要美化面部、改变身材、重构背景或重新调色。
```
