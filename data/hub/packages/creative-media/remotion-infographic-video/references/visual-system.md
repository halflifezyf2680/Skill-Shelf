# Visual System

Use this system for technical infographic videos.

## Palette

- background: `#f7f3ea`
- text: `#141414`
- navy: `#14213d`
- teal: `#0f8b8d`
- orange: `#e16f24`
- red: `#d9333f`
- muted text: `#536071`
- panel fill: `rgba(255, 253, 247, 0.94)`
- warm chip: `#f1eadc`

## Layout Grammar

- Title band: eyebrow plus large direct headline.
- Main band: flow, split comparison, grid, pipeline, or timeline.
- Result band: SQL output, MCP output, evidence, risk, next checks, recall-ready state, or summary strip.

## Components

- Flow card: icon, title, one evidence line.
- Evidence card: source, entity/path, detail.
- Result strip: dark navy, monospace technical labels.
- Timeline event: date/entity, reason, status tag.
- Recall panel: wide recall candidates on the left, strict evidence on the right.
- Audit split: noisy baseline on the left, structured harness on the right.

## Typography

- Use large, bold headings.
- Use monospace for code, paths, tool names, and database fields.
- Do not scale font size with viewport width.
- Keep letter spacing at `0`.
