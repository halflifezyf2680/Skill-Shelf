# Layout Checklist

Before final delivery:

- Generate still frames for every changed scene.
- Inspect at the most information-dense frame, not just frame 0.
- Fill large empty lower thirds with result, evidence, next-step, or timeline content.
- Check Chinese and English mixed labels for wrapping.
- Check code paths and function names for clipping.
- Ensure icon buttons or labels do not resize fixed-format boards.
- Hide global corner marks when they collide with cards.
- Run `npm run check`.
- Run `npm run render` only after stills are clean.
