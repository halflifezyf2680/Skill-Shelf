# 风格预置库

本文件只保存已经由用户确认的、可跨题材复用的视觉锁。每个锁只覆盖不应在同一图像系列中漂移的视觉语言，不定义场景内容、主体、构图或故事。

## 国风仙侠原画

**调用名**：国风仙侠原画

**技术标签**：二次元国风仙侠原画风格、精修数字插画质感

**一句话记忆**：二次元国风仙侠原画，以精修数字插画完成度呈现人物、器物与东方奇幻空间。

**适用范围**：国风仙侠的人物、场景、建筑、器物与叙事插画；也可用于东方奇幻主视觉。

**Style lock**

```text
二次元国风仙侠原画风格，精修数字插画质感，而非真人肖像、照片写实或 3D 渲染。人物采用理想化、设计化的比例与清晰五官，发丝和服饰按结构分组；场景、建筑与器物采用东方奇幻的形状语言、明确的材质分区和可读的中远景层次。以干净线条、准确边缘、受控色块和细腻数字渐变塑造形体；织物、皮革、金属、漆木、石材、植被与建筑表面各自可辨，但保持图形化概括，不追求摄影级微观真实。

笔触仅服务局部体积转折，不能成为主体纹理。主视觉与关键设计保持高可读性，非焦点区域通过清晰层级、低对比色块和有限空气透视后退。色彩脚本由本次场景决定，但保持东方色彩关系、通透中间调与克制集中的高光；亮部保留色彩与材质转折，暗部有明确结构锚点，空气透视只降低最远层的饱和度与局部对比度，不以泛白、bloom、逆光洗白或远景过曝制造空间感。
```

**纹理与细节护栏**：优先描绘可归属到设计或材质的细节，例如服装分层、饰物结构、布料织纹、金属边缘、漆木雕刻、石材层理与建筑构件；这些细节服务于主视觉和一至两个次要信息群。笔触只负责局部体积转折，不能铺满主体、不能替代材质、不能形成显眼的干刷条纹或破碎色块。

**光色与曝光护栏**：默认避免高调泛白。用中间调承载主体内部结构，以一至两个深色锚点稳住每个焦点群；浅色人物、建筑或道具也必须保留冷暖阴影、褶皱或材质转折，不能漂白成单一亮色块。除非用户明确要求雪景、极端逆光或梦境高调，禁止大面积纯白、乳白雾化、泛光、高光溢出和远景过曝。

**防漂移项**：不要替换为真人肖像、照片写实、真实皮肤毛孔与皱纹、3D 渲染、平滑喷枪式厚涂、粗重且抢眼的笔刷感、随机干刷、破碎色块、平均化微纹理、照片感噪点、大面积均匀噪点、bloom、奶油雾感、逆光洗白或高光溢出。

## 极繁钢笔

**调用名**：极繁钢笔

**技术标签**：钢笔线稿、分级排线、有限平涂、焦点极繁

**一句话记忆**：深靛黑钢笔线条主导画面，大片呼吸空间衬托焦点处的极繁幻想结构。

**适用范围**：奇幻城市、建筑、遗迹、怪物、景观与角色场景；适合需要图形化线稿、仪式性装饰和清晰焦点密度的题材。

**Style lock**

```text
清晰图形化的钢笔幻想插画，以深靛黑钢笔线稿为主导，而非照片、平滑数字厚涂或 3D 渲染。用明确的线条层级组织景深：前景大形、主角轮廓、入口与焦点建筑使用粗重深色轮廓；中景使用中等线条；极细线只用于焦点区域的装饰。阴影由有方向的排线、交叉排线与少量实黑暗部建立，不以柔软数码阴影代替。色彩仅作为线稿下方的有限透明色洗或平涂，所有关键线条保持清晰可读。

将极繁细节集中在一个主焦点与至多一个次要结构：可使用植物卷饰、马赛克、窗棂、根系、藤蔓、仪式器物、装饰桥或微型建筑群，但必须形成可读的结构簇，不得均匀铺满全画面。天空、远景和非焦点平面保持开阔、简化并留出安静色块，使线密度、装饰密度与对比度从焦点向外递减。
```

**纹理与细节护栏**：所有细节由线条、排线和装饰结构承担；先确定主焦点与一条清晰观看路径，再增加微型纹样。不要把细线、排线、藤蔓或窗棂扩散为背景噪点；色彩始终从属于深色钢笔线稿。

**防漂移项**：不要替换为照片写实、柔软彩铅、厚涂模糊、均匀细线、全画面同等极繁装饰、通用中世纪城堡、文字、标志、水印或 UI 元素。

## 精修主视觉

**调用名**：精修主视觉

**技术标签**：半写实、精修、平滑块面、色调可变

**一句话记忆**：干净精修的数字奇幻主视觉，清晰结构与柔和空气感并存，色调可自由切换。

**适用范围**：高完成度的奇幻或科幻环境、角色、建筑与宣传主视觉；适合需要精确结构、精细装饰和清爽画面完成度的题材。

**Style lock**

```text
高完成度的半写实数字奇幻插画，具有精修的游戏主视觉质感，而非摄影式真实或 3D 成片渲染。以干净平滑的色块、精确的结构边缘和受控的细密装饰塑造形体；保留少量有意的绘画概括，但不突出粗糙干刷、破碎笔触或厚重颜料肌理。主体与关键设计保持锐利可读，远处通过柔和的低对比空气透视自然退后。色彩脚本由本次画面决定：可自由切换冷暖、明暗与主色家族，但保持清晰的明度层级、克制且集中的强调色，以及通透、干净的整体光感。
```

**防漂移项**：不要替换为照片、真实摄影光学噪点、未处理的 3D 渲染、粗粝厚涂、显眼的干刷笔触、平均化的微纹理或失控的彩色高光。

## 水墨奇境

**调用名**：水墨奇境

**技术标签**：数字水墨、皴擦干刷、纸本肌理、色调可变

**一句话记忆**：以克制水墨质感衬托清晰焦点，实处立住、虚处化开，不把纹理铺满全画面。

**适用范围**：东方奇幻、神话史诗、古典建筑、山水环境与角色概念绘画；适合需要手绘仪式感、苍茫空间与画卷气质的题材。

**Style lock**

```text
东方水墨意境与数字概念插画融合的半写实绘画，而非平滑 CG 渲染或传统单色水墨复制。以清晰、干净的大形与可读轮廓承载主视觉；中远景中承担叙事的建筑、地形与器物保持可辨的色块、明暗面和选择性结构边缘。仅将湿画晕染和松散墨色团块用于最远背景与雾气过渡，将少量干刷皴擦用于地形或结构的阴影转折，纸本颗粒只作为极轻的底质而非满画面噪点。精细线描只服务主焦点的轮廓及一两个识别细节，其余区域以概括色块和留白收束；最远空气层可以化开，但不得把中远景整体雾化或虚焦。色彩可随本次题材自由切换；使用明确的主色、干净的中高明度区域与有限强调色建立层级，不默认低饱和、暖褐或陈旧感。整体保留克制的手绘水墨气息与诗性空间。
```

**纹理与细节护栏**：主视觉优先保持干净的轮廓和大形；每张图最多让一个主视觉与两个次要信息群精细可读。湿画、皴擦和破边仅出现在最远环境或空气过渡区，不能同时覆盖主体、背景和所有道具；中远景的关键结构即使概括也必须保持可辨剪影和硬朗明暗面。未被指定为焦点的物体可以概括，但不能一律化成雾或虚焦。画面的丰富度优先来自大、中、小形体之间清楚的层级、嵌套、遮挡、材质分区与明暗关系，而非用大量微小线条、散点、碎片或重复装饰填满画面。精细信息应聚集在主焦点及有限的次焦点中，并以连续、可归属的结构呈现；其余区域保留完整剪影、连续色块和可呼吸的平面。不得让不同区域以相同密度竞争细节，不以平均化微纹理、零散高光或交错线性元素替代层级。

**防漂移项**：不要替换为纯传统水墨、平滑 CG、照片、3D 成片渲染、干净矢量线稿、满画面颗粒噪点、全局干刷皴擦、暖褐脏灰的统一滤镜、均匀写实纹理或高饱和霓虹配色。

## 黑白线稿

**调用名**：黑白线稿

**技术标签**：纯黑白、钢笔线描、分级线宽、克制排线

**一句话记忆**：以清晰黑色钢笔线和留白组织叙事，细节集中、阴影简洁，不杂乱也不草率。

**适用范围**：人物、场景、事件、道具、建筑与分镜；适合需要可读结构、动作关系和黑白线稿质感的题材。

**Style lock**

```text
干净、高完成度的纯黑白钢笔线稿插画，以白纸留白与纯黑墨线构成画面，不使用任何彩色、彩铅、灰阶涂抹、照片质感、数字厚涂或 3D 渲染。用稳定清楚的轮廓线、受控的粗细变化和准确的结构线组织人物、场景与物件：主视觉、前景遮挡与关键动作使用较粗的实黑线；中景结构使用中等线宽；极细线只用于主焦点的材质、表情或必要构造。让画面具有可读的形体、尺度、空间与动作关系，而不是松散草图或均匀的装饰性线网。

阴影只由稀疏、方向一致的单向排线、有限交叉排线和小面积实黑暗部表达；每一组排线必须贴合明确的体积、材质或光向。保留大面积干净白纸作为光面和非焦点区域，使线条密度、黑白对比和细节复杂度从主焦点向外逐级降低。每幅画仅让一个主视觉与至多两个次要信息群达到精细刻画，其余内容以清楚剪影、概括结构和必要识别特征收束。整体呈现专业手绘钢笔分镜/插画线稿的秩序、明确性和呼吸感。
```

**纹理与细节护栏**：细节必须附着于表情、手势、服装结构、物件功能、建筑构件或材质转折；不要用抖动轮廓、重复短线、无方向乱线或满幅交叉排线制造“手绘感”。远景可简化，但仍保留一个可辨的结构、明暗面或尺度锚点；不要整体虚化。

**光色与曝光护栏**：固定纯黑白，不加入综合色、米黄纸、蓝黑墨、色洗或灰色喷枪渐变。以白纸为主基调，纯黑只用于轮廓重点、遮挡关系和必要深阴影；避免大面积死黑吞没主体，也不要用灰雾削弱对比。

**防漂移项**：不要替换为铅笔素描、彩铅、速写涂鸦、炭笔污渍、漫画网点、均匀线宽矢量图标、密集无方向排线、满幅纹理噪点、模糊水彩晕染、真实摄影、厚涂、3D 渲染、文字、标志、水印或 UI 元素。
