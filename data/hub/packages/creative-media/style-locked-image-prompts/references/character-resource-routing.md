# 角色资源路由与槽位控制

只在 `SKILL.md` 已判定需要角色资源时读取本文件。先做镜头与景别决策，再选择资源；用户参考图、已确认锚点与明确局部要求的优先级最高。

## 调用模式速查

| 模式 | 触发 | 可读取资源 | 禁止 |
| --- | --- | --- | --- |
| 保留 | 参考图、既有人设、保持不变 | 仅用户要求变更的层 | 重选脸型、服装、发型或全套 |
| 局部 | 只改一个层 | 对应单一资源小节 | 顺势补全其他层 |
| 最小 | 仙侠主视觉、信息泛化、人物设计可读 | 一服装 + 一发型；兼容预置且脸可读时加最小面部锚点 | 饰品、武器、宝具的无理由添加 |
| 完整 | 明确角色设定/立绘/全套造型 | 所有有叙事依据的层 | 为凑数量而加挂件 |
| 跳过 | 远景、背影、群像次要、环境主导或非角色修改 | 无 | 读取角色资源 |

## 预置与景别裁剪

| 条件 | 面部写入 | 角色锚点写入 |
| --- | --- | --- |
| 国风仙侠原画 / 精修主视觉 + 特写 | 脸型、眉眼、鼻唇、识别点、选择性妆面/光影 | 发际线与可见头饰 |
| 同类预置 + 半身 | 脸型、眉眼关系、识别点、发际线 | 发型、上身轮廓、胸前/肩部可见件 |
| 三分之二身 | 脸型、眼型或情绪、发际线 | 服装轮廓、腰侧/背部可见件 |
| 全身或远景 | 不写五官包 | 头部剪影、发型、主服装、一个身份点 |
| 水墨、钢笔或黑白线稿 | 仅在明确设计脸时写脸型、眉眼、口角 | 禁止写肤质、彩妆和细密高光 |

## 槽位表

| 槽位 | 上限 | 可占用内容 | 冲突规则 |
| --- | --- | --- | --- |
| 头部 | 1 焦点 | 发型默认头饰、冠、簪、额饰 | 发型默认头饰优先；不得再叠第二顶冠或头部大饰 |
| 颈胸 | 1 主件 | 压襟、颈牌、短项坠、护心镜、胸前工具 | 护心镜与大型胸前工具优先；不再叠主坠 |
| 左腰 / 右腰 | 每侧 1 重件 + 1 薄件 | 剑鞘、禁步、重佩、工具囊、药筒、薄囊、令牌 | 重件优先；同侧只再允许一个薄件，服装自带囊袋先占用 |
| 手腕 / 前臂 | 每侧 1 | 护腕、玉扣、镯、射鞴、护掌 | 功能护具优先于装饰；不得与服装自带护腕重叠 |
| 背部 | 1 | 背囊、书箧、背篓、斜挂经卷筒、背负长兵器 | 只能选择一个；背部容器优先于非必要背负物 |
| 手持 | 每只手 1 任务物 | 武器、灯、宝具、工具、缰绳 | 动作优先；正在战斗的持武器手不再拿宝具或工具 |
| 肩背披挂 | 1 | 肩披、短斗篷、斜挂带 | 服装自带肩披优先；不叠第二层大披挂 |

## 冲突与写入

1. 先锁定服装的必须保留项，再锁定发型/头饰，再选择功能装备，最后考虑饰品与宝具。
2. 两件物品争同一槽位时，保留用户明确指定项；其次保留任务必需项；再保留服装必须保留项；最后删除可选的装饰性项。
3. 不把不可见细节写进当前镜头。保留连续性时只记载可见锚点，不用一长串隐藏装备充数。
4. 最终提示词写入顺序固定为：`Style lock → 镜头/景别 → 角色连续性锚点 → 当前可见脸部与装造 → 动作、场景、光线、空间约束`。
