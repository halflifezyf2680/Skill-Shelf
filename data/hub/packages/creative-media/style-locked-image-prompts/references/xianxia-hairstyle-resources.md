# 仙侠发型与头饰资源库

由 `SKILL.md` 的统一路由决定调用：最小或完整模式可调用发型，局部模式只在用户请求发型、束发、头饰、冠饰或换发型时调用。每款先定义发型，再给一个默认低风险头饰；用户要求“仅发型”则移除头饰。每款使用“主结构、辅助结构、头饰焦点”的三点预算，并占用一个头部槽位。兽耳、角、鳞片等种族特征不属于本库。

## 男性发型

### 素束低髻

**适用对象**：外门弟子、杂役、普通日常。  
**一句话记忆**：干净低髻配一根素簪。  
**结构 / 视觉等级**：朴素。中分或微偏分，额前梳净，太阳穴各留极短碎发；全部头发收至后脑偏下，盘成扁圆小髻，髻根贴近头部，不留长尾。横向木簪穿过髻根固定。  
**必须保留**：后脑低位扁圆髻；横向素木簪；整洁无垂坠。  
**可省略 / 防漂移**：极短鬓发可删；不要高冠、长马尾、散发和华丽金属饰。

### 半束短发

**适用对象**：少年修士、山野角色、轻便日常。  
**一句话记忆**：上半束起、下半短发自然落。  
**结构 / 视觉等级**：朴素轻快。前发三七分，眉上保持清楚；头顶至耳上方的头发收成小半髻，后发只到肩上或颈后，不超过肩；用一段窄布发带在半髻根部打结。  
**必须保留**：耳上小半髻；肩上短后发；窄布发带。  
**可省略 / 防漂移**：一侧细碎鬓发可删；不要长及腰的散发、双马尾或成年礼冠。

### 高束马尾

**适用对象**：剑修、游侠、行动型主角。  
**一句话记忆**：头顶偏后高束，马尾清楚而不乱飞。  
**结构 / 视觉等级**：亮眼战斗型。前发向后梳起，额前只留两束短而贴面的鬓发；发根固定在头顶后缘，马尾从高点垂到肩胛下方，尾端自然收尖。用宽发带绕髻根两圈，发带末端不超过肩。  
**必须保留**：头顶偏后高束点；肩胛下长马尾；短尾宽发带。  
**可省略 / 防漂移**：贴面短鬓可删；不要马尾拖至腰、发带长如飘带、复杂冠饰。

### 发带束发

**适用对象**：散修、旅者、猎修、远行角色。  
**一句话记忆**：后脑束发配一条有实用长度的发带。  
**结构 / 视觉等级**：朴素实用。前发从额头向两侧梳平，耳后无大鬓角；全部头发在后脑中低位束成短尾，尾端只到肩下。窄布发带绕额一圈后在后脑打结，结尾仅垂至肩，不遮脸。  
**必须保留**：后脑中低位短尾；绕额窄发带；无发髻无冠。  
**可省略 / 防漂移**：发带低对比边纹可删；不要忍者额带、长飘带、蓬松卷发。

### 低马尾侧鬓

**适用对象**：文修、医修、温和或成熟角色。  
**一句话记忆**：低马尾与一侧收拢鬓发的温雅款。  
**结构 / 视觉等级**：清雅。偏分前发向两侧贴顺，右侧鬓发向耳后收拢，左侧留一束弧形短鬓；其余头发在后颈束成低马尾，长度到肩胛中部。用一枚扁平玉扣或布结收束，不带垂珠。  
**必须保留**：后颈低马尾；单侧弧形短鬓；扁平扣收束。  
**可省略 / 防漂移**：扣面小纹样可删；不要披肩散发、左右对称双鬓或女性化步摇。

### 冠巾束髻

**适用对象**：儒修、阵师、书院身份、正式课业。  
**一句话记忆**：小髻压在简洁冠巾下，身份感来自轮廓。  
**结构 / 视觉等级**：清雅正式。前发中分后完全向后梳，后脑偏上盘成紧凑圆髻；一顶软质低冠巾覆盖髻根，冠高不超过头部高度三分之一，前缘平直，后部露出少量髻形。冠巾用一根横向簪固定。  
**必须保留**：后脑偏上圆髻；低矮软冠巾；横向固定簪。  
**可省略 / 防漂移**：冠边一圈暗纹可删；不要皇帝冕冠、道士高冠、巨大帽翅。

### 半披长发

**适用对象**：清冷散修、隐士、病弱或特殊气质角色。  
**一句话记忆**：上半束稳住脸部，下半长发只做干净竖向线条。  
**结构 / 视觉等级**：亮眼克制。中分前发贴向耳后，头顶一小束收为扁平半髻；其余直发从肩后自然垂至胸下或肩胛下，不越过腰。半髻横插一根细玉簪，发尾整齐，不让大面积头发遮住肩颈和衣领。  
**必须保留**：顶部扁平半髻；胸下长度的直后发；横向细玉簪。  
**可省略 / 防漂移**：耳前极细发束可删；不要全散长发、风中乱飞、瀑布般拖地长发。

### 编发束尾

**适用对象**：边地修士、御兽师、风/木属性角色。  
**一句话记忆**：一条实用主辫收进短尾。  
**结构 / 视觉等级**：实用亮眼。前发向后梳净，左右太阳穴各有一条细辫向后汇合；所有头发在后脑中位束起后编成一条粗而清晰的三股辫，长度到肩胛下，尾端用皮绳固定。只在辫根嵌一枚木质或骨质小扣。  
**必须保留**：两条太阳穴细辫；一条后背主三股辫；皮绳尾结。  
**可省略 / 防漂移**：辫根小扣可删；不要满头细辫、异域刻板元素、金属链条满挂。

### 高髻发冠

**适用对象**：世家嫡传、少主、正式宴会。  
**一句话记忆**：高束髻与一顶只包髻根的窄冠。  
**结构 / 视觉等级**：华贵非仪式级。额前中分梳净，头发在头顶偏后盘成竖向椭圆高髻，高度不超过额头至下巴距离的一半。窄发冠仅环抱髻根，前缘低、后缘略高，冠面一处玉片或金属压纹，不垂珠。  
**必须保留**：竖向椭圆高髻；仅包髻根的窄冠；单一冠面焦点。  
**可省略 / 防漂移**：冠面暗纹可删；不要帝王冠、羽毛大冠、满头珠串。

### 完整冠髻

**适用对象**：掌门、仙官、仪式或终局角色。  
**一句话记忆**：完整冠体压住高髻，正面轮廓庄重且不过高。  
**结构 / 视觉等级**：仪式级。前发完全收净，头顶后方盘成紧实高髻；完整硬质冠从额顶跨至髻后，冠体高度约头高四分之一，前低后略高，侧面不伸出夸张翼片。冠正中只嵌一枚扁平徽记，用暗色簪从两侧固定。  
**必须保留**：紧实高髻；前低后高完整冠；冠正中扁平徽记。  
**可省略 / 防漂移**：两侧暗簪可删；不要冕旒、巨大王冠、漂浮光环。

## 女性发型

### 素净低髻

**适用对象**：山门日常、外门弟子、普通女修。  
**一句话记忆**：后颈低髻配一根素簪。  
**结构 / 视觉等级**：朴素。中分或微偏分，额前梳净，耳侧各留极短软鬓；全部头发在后颈盘成贴头扁圆髻。横向穿一根木簪或细玉簪，簪首不超过一枚小圆珠。  
**必须保留**：后颈扁圆低髻；一根横簪；极少垂坠。  
**可省略 / 防漂移**：软鬓可删；不要高髻、大花、步摇或散发。

### 低束长发

**适用对象**：采药、旅居、温和日常。  
**一句话记忆**：后颈低束，长发仍便于行走。  
**结构 / 视觉等级**：朴素轻柔。偏分前发贴向耳后，后发在后颈用布带束成低马尾，长度到肩胛下方；两侧只留一对贴面短鬓，发尾自然但整齐。布带结尾到肩，不使用簪钗。  
**必须保留**：后颈低马尾；短尾布带；一对贴面短鬓。  
**可省略 / 防漂移**：布带窄边可删；不要腰长散发、大量卷发、豪华头饰。

### 半披直发

**适用对象**：清冷散修、月/水属性、隐居角色。  
**一句话记忆**：小半髻控制脸部，下半直发保持安静。  
**结构 / 视觉等级**：清冷亮眼。中分前发向耳后收，头顶一小束盘成扁平半髻；余发直顺垂到胸下，不超腰。半髻以一根细银簪或月牙形扁扣固定，耳前只留两束极细短发。  
**必须保留**：扁平半髻；胸下直发；细银簪或月牙扁扣。  
**可省略 / 防漂移**：极细耳前发束可删；不要白雾般散发、多条披帛混入发间、满头水晶。

### 高束马尾

**适用对象**：剑修、弓手、行动型女主。  
**一句话记忆**：高束点明确，马尾不超过肩胛下。  
**结构 / 视觉等级**：战斗亮眼。前发向后收紧，额前保留一撮薄刘海或两束短鬓，二选一；头顶后缘束起高马尾，长度到肩胛下。以宽发带绕根两圈，发带尾仅至肩；后颈与耳侧完全清爽。  
**必须保留**：头顶后缘高束点；肩胛下马尾；短尾宽发带。  
**可省略 / 防漂移**：薄刘海/短鬓中未选的一项不出现；不要腰长马尾、蝴蝶结、长飘带或步摇。

### 编发低马尾

**适用对象**：猎修、御兽、山野角色。  
**一句话记忆**：两条细辫汇入后颈低马尾。  
**结构 / 视觉等级**：实用。前发偏分，左右鬓角各编一条贴头细辫，向后汇入后颈低马尾；马尾到肩胛中部，尾端用皮绳或布绳固定。辫根仅一枚木扣，无垂珠。  
**必须保留**：两条贴头鬓辫；后颈低马尾；皮绳尾结。  
**可省略 / 防漂移**：木扣可删；不要满头复杂辫、游牧刻板符号、花环。

### 双低髻

**适用对象**：少女、外门弟子、活泼角色。  
**一句话记忆**：耳后两枚低而小的圆髻。  
**结构 / 视觉等级**：朴素活泼。中分前发梳平，耳前各留一缕短鬓；在后脑左右、略低于耳顶的位置盘两枚同样大小的扁圆小髻，髻距保持一掌左右。每髻只横插一根短簪或同色布结。  
**必须保留**：后脑耳后双低髻；左右等大；一对短簪或布结。  
**可省略 / 防漂移**：短鬓可删；不要头顶双丸子、巨大蝴蝶结、幼儿化夸张装饰。

### 双环髻

**适用对象**：乐修、舞者、幻术、庆典场景。  
**一句话记忆**：头顶两枚完整发环，头饰只在环根。  
**结构 / 视觉等级**：惊艳表演型。前发中分后梳起，在头顶左右形成两枚竖向圆环髻，环体高度不超过头高三分之一，左右对称；后发收成短束藏在环根后，不披散。每个环根各有一枚小花钿或细短簪，不垂珠。  
**必须保留**：头顶左右双竖环；对称高度；环根一对小花钿。  
**可省略 / 防漂移**：额前薄发片可删；不要巨型兔耳环、长散发、战斗时使用步摇。

### 侧髻

**适用对象**：世家、成熟优雅、宴会。  
**一句话记忆**：发髻偏右后侧，装饰顺着髻的弧线插。  
**结构 / 视觉等级**：惊艳优雅。偏分前发向两侧贴顺，左侧鬓发收至耳后，右后脑偏侧盘成扁椭圆侧髻，位置不低于耳顶也不高于头顶。沿髻外弧斜插一支双股钗，钗首只一朵小花或一枚玉片。  
**必须保留**：右后侧椭圆侧髻；单侧弧形钗；左右鬓发不对称收束。  
**可省略 / 防漂移**：一束短鬓可删；不要髻偏到肩上、满头簪花或双侧对称髻。

### 高髻

**适用对象**：医修、书修、成熟日常、正式课业。  
**一句话记忆**：高而紧凑的单髻，簪只横穿髻根。  
**结构 / 视觉等级**：清雅正式。中分或微偏分，额前无厚刘海；头发在头顶偏后盘成紧实圆锥高髻，高度约头高三分之一。髻根横穿一支细长簪，簪首是极小药草、书卷或几何形，不带坠饰；耳后清爽。  
**必须保留**：头顶偏后单一高髻；横向细长簪；无垂珠。  
**可省略 / 防漂移**：极短软鬓可删；不要唐式巨大高髻、花冠、蓬松卷发。

### 盘髻配发簪

**适用对象**：阵师、贵女、正式课业或访客。  
**一句话记忆**：后脑盘髻与一根有方向的主簪。  
**结构 / 视觉等级**：亮眼正式。前发偏分并压向耳后，后脑中高位盘成宽而扁的横向盘髻，边缘能看到一圈清晰盘发纹理。主簪从左下斜穿至右上，簪首只放一枚扁平宝石、叶片或几何片；不叠第二根大簪。  
**必须保留**：后脑中高横向盘髻；左下至右上的主簪方向；单一扁平簪首。  
**可省略 / 防漂移**：耳前薄鬓可删；不要多根大簪、皇冠、步摇群。

### 高马尾配额带

**适用对象**：战舞、火/雷属性、英气角色。  
**一句话记忆**：额带稳住额前，高马尾让动作有方向。  
**结构 / 视觉等级**：战斗惊艳。额前头发向后收净，仅留两束短鬓；窄额带从额头发际横过、在后脑高束点下固定。马尾在头顶后缘高束，至肩胛下，尾端略分束但保持一条主形。额带只有一道暗纹或一枚中央扁扣。  
**必须保留**：发际横向窄额带；高束马尾；中央单一扁扣或暗纹。  
**可省略 / 防漂移**：短鬓可删；不要现代运动发带、长飘带、额头宝石链或复杂冠。

### 半披卷发配额饰

**适用对象**：成年魅修、成人幻想系、静态宴会。  
**一句话记忆**：半髻固定卷发，额饰只在前额中央。  
**结构 / 视觉等级**：性感成熟但克制。中分前发向后并成低扁半髻，余发以大而疏的波浪卷垂到胸下，不超过腰；耳前各留一束明显卷发。额前中央仅一枚小型水滴、叶片或弯月额饰，以细链贴发际连接到两侧，不下垂到眉眼。  
**必须保留**：低扁半髻；胸下疏大卷发；前额中央单一小额饰。  
**可省略 / 防漂移**：耳前卷发可删；不要满头小卷、王冠、宝石面帘或遮脸刘海。

### 低髻配窄冠

**适用对象**：圣女、冰/水属性、庄重角色。  
**一句话记忆**：低髻被一圈窄冠稳定地框住。  
**结构 / 视觉等级**：庄重亮眼。中分前发整齐贴向耳后，后颈盘成低而宽的椭圆髻；一圈细窄半冠从两侧太阳穴沿头顶后缘框住髻根，冠高不超过一指半，前额不压低。冠中央只一枚月牙或水滴扁片，无垂珠。  
**必须保留**：后颈宽椭圆低髻；沿头顶后缘的窄半冠；中央单一扁片。  
**可省略 / 防漂移**：极短软鬓可删；不要王冠、水晶花环、多层珠帘。

### 华丽高髻配步摇

**适用对象**：世家贵女、礼宴、静态正式场合。  
**一句话记忆**：高髻只配一支侧步摇，垂饰止于耳上。  
**结构 / 视觉等级**：华丽。前发中分向上拢起，头顶偏后盘成饱满圆锥高髻，高度不超头高一半；右侧鬓发贴顺，左侧仅留一束短弧鬓。左侧斜插一支步摇，主枝贴髻，珠玉垂饰只两至三串、长度止于耳上缘，不能扫到肩。  
**必须保留**：饱满单一高髻；单侧一支步摇；垂珠止于耳上。  
**可省略 / 防漂移**：短弧鬓可删；不要双侧步摇、满头凤冠、战斗/骑乘场景使用。

### 仪式冠髻

**适用对象**：掌门、神使、飞升、终局仪式。  
**一句话记忆**：高髻与完整冠体形成一个干净的仪式轮廓。  
**结构 / 视觉等级**：仪式级。前发全向后收，头顶后方盘成紧实高髻；完整冠体从额顶延至髻后，前缘低、后缘略高，整体高度约头高四分之一。冠正中只有一枚可辨的宗门徽记，两侧以暗簪固定；没有珠帘、长垂链或第二层发冠。  
**必须保留**：紧实高髻；前低后高完整冠；冠正中单一徽记。  
**可省略 / 防漂移**：两侧暗簪可删；不要皇后凤冠、光环、漂浮头饰、数十颗宝石。
