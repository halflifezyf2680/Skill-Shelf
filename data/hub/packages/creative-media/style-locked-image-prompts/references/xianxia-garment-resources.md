# 仙侠服装资源库

由 `SKILL.md` 的统一路由决定调用：仅在局部、最小或完整模式包含服装层时读取，不自行要求用户明确点名。资源只定义服装：不含发型、头饰、首饰、武器、宝具、人物外貌或场景。每套遵循“三主识别点、两辅助结构、一项可省略细节”的预算；远景可删“可省略”，不可删“必须保留”。服装“必须保留”和“辅助”中自带的腰囊、护腕、肩披、背部容器或头部件会占用对应槽位，后续资源不得重复叠加。

## 通用覆写

一次仅调用一套主服装。属性覆写只能改内衬/夹层色、领缘或下摆的一道纹样、一个边缘材质、一处小型灵性结构；不得重做领型、袖型、衣长、轮廓、穿衣层次或活动方式。水系用冷色内衬、细鳞/水波织边与润泽包边；火系用耐热内层、焦金压纹与炭色包边；木系用叶脉压纹、木扣或苔绿夹层；雷系用断续几何纹与深银窄边；土系用厚织带、岩纹包边与稳重低彩度。灵性结构只可有一处，不能使整件衣服发光。

## 男装

### 山门素衣

**适用对象**：外门弟子、杂役、新入门修士、山门日常。  
**一句话记忆**：干净、耐穿、不显贵的门派练功衣。  
**视觉等级 / 基础结构**：朴素；直而轻收腰的 H 形。交领右衽窄袖长衫至小腿中段，外面只系同色窄布腰封；直筒裤裤脚收入及踝布靴，左右侧摆从膝上浅开衩。棉麻或细布，低明度门派色配无图案浅内襟，袖口仅一道窄滚边。  
**必须保留**：窄袖交领长衫；平整窄布腰封；直筒裤收入布靴。  
**辅助 / 可省略**：左腰素木门牌；袖口滚边可省略。  
**防漂移**：不要贵族大袖、飘带、重甲、满身灵纹。

### 游方散修

**适用对象**：旅者、采药人、无门派散修。  
**一句话记忆**：走远路也整洁的旧旅装。  
**视觉等级 / 基础结构**：朴素实用；短上长下的轻倒梯形。贴腕交领短袍至膝上，外罩无袖前短后长及臀罩衫，背部压一块耐磨肩片；宽布带固定左腰扁囊，外袍高开衩露直筒裤，小腿两道绑带收进厚底短靴。灰、褐、靛粗布，仅允许一至两块修补。  
**必须保留**：前短后长无袖罩衫；背部耐磨肩片；绑腿厚底短靴。  
**辅助 / 可省略**：卷起的防雨短斗篷；布补可省略。  
**防漂移**：不要乞装、商贾华服、全身皮甲或巨型斗篷。

### 青衫书修

**适用对象**：儒修、符师、阵师、书院弟子。  
**一句话记忆**：安静清正、可伏案掐诀的文修常服。  
**视觉等级 / 基础结构**：清雅；上宽下直的修长 H 形。白交领中衣外穿青、黛或墨色直身长衫，长至踝上；袖根宽、腕口收窄，两枚布结固定前襟。细布绦束腰，两侧膝部开衩露深色直裤与薄底靴；平整细布或暗纹丝麻，暗纹只在领缘和下摆内侧。  
**必须保留**：宽根收腕袖；直身长衫膝部开衩；细布绦。  
**辅助 / 可省略**：右腰扁符囊；内侧几何暗纹可省略。  
**防漂移**：不要拖地宽袍、宫廷官服、道士法衣或满挂卷轴。

### 丹坊药师

**适用对象**：医修、炼丹师、药庐弟子、毒师。  
**一句话记忆**：收好袖口、腰侧能取药的工作服。  
**视觉等级 / 基础结构**：实用而职业清楚；重点在无袖罩衣与腰封。窄袖交领短袍的腕口用窄带收紧；外罩及大腿中段无袖对襟比甲，前襟平整，侧面开衩。前方半围腰从腰至大腿，两只扁药囊嵌入主腰封；裤装配防滑短靴。耐污哑光织物，比甲仅一圈硬挺或薄皮包边。  
**必须保留**：收紧袖口；及大腿无袖对襟比甲；前半围腰与两只扁药囊。  
**辅助 / 可省略**：一只半指护套；草叶压纹可省略。  
**防漂移**：不要厨房围裙、医官白袍、满挂玻璃瓶或兽骨巫医装。

### 灵植农修

**适用对象**：灵植师、园圃弟子、御兽杂役。  
**一句话记忆**：短褂、围腰、护臂都为山门劳作服务。  
**视觉等级 / 基础结构**：朴素功能性；直腰短上衣配稳重下盘。立领或浅交领窄袖短褂过腰，外罩到膝的前开短马甲并在两侧开衩；宽布围腰只带一个横向工具袋。宽松裤装在小腿收束，厚布绑腿进耐泥短靴；腕至小臂中段配旧布护臂。苔绿、土黄、灰褐耐磨布。  
**必须保留**：过腰短褂；到膝前开马甲；护臂与绑腿。  
**辅助 / 可省略**：横向工具袋；木扣可省略。  
**防漂移**：不要蓑衣斗笠、森林精灵礼服、藤蔓缠身或武侠劲装。

### 夜行影修

**适用对象**：斥候、潜入者、夜巡影修。  
**一句话记忆**：不反光、不摆动、面部仍可见的夜行层次。  
**视觉等级 / 基础结构**：冷峻亮眼；深色贴身高交领短衣，手腕脚踝完全收束。外层单侧斜襟短外袍：右前摆至大腿上段，左后摆至膝后，髋侧固定成不对称轮廓。宽腰封平整无垂物，弹性窄裤配无响软底长靴；吸光哑布，斜襟仅一道更深压纹。  
**必须保留**：高交领贴身内层；不对称短外袍；无挂件宽腰封。  
**辅助 / 可省略**：左前臂窄护腕；后腰收纳缝可省略。  
**防漂移**：不要遮全脸、忍者制服、未来战术服、飘带或长披风。

### 行剑侠客

**适用对象**：剑修、游侠、护送者、常规主角。  
**一句话记忆**：右肩承力、左后腰佩剑的利落行走剑装。  
**视觉等级 / 基础结构**：亮眼非礼服；贴腕交领长衣至膝上，叠无袖斜开襟及臀短褙。右肩以宽布带压住，左侧轻薄；双层平整布革腰封在左后腰预留剑鞘固定位。腰封下接两片不对称前摆：右至大腿中段，左至膝下并开衩；窄裤配包踝软靴。细纹哑布，只有肩带和腰封边使用磨旧皮革。  
**必须保留**：右肩承力带；左后腰剑位；长短不同两片前摆。  
**辅助 / 可省略**：左前摆压纹；右腕短护腕可省略。  
**防漂移**：不要书生宽袍、全身重甲、西式皮衣或满身金属挂件。

### 镇煞武修

**适用对象**：体修、护卫、镇妖者、近战弟子。  
**一句话记忆**：布衣打底、半甲护躯干、关节保持自由。  
**视觉等级 / 基础结构**：战斗级；深色窄袖交领短袍到臀下，外穿前后两片软札半甲。胸腹由三至四排宽甲札叠合，腰部布带固定；左肩一块略大护肩，右肩只用皮带收束。短甲裙叠在窄裤外，配护胫与厚底靴。哑光漆革、布与少量暗铁边，纹样只允许胸中央护符片。  
**必须保留**：前后两片软札半甲；不对称护肩；短甲裙加窄裤。  
**辅助 / 可省略**：胸口护符片；掌护套可省略。  
**防漂移**：不要西式板甲、全覆盖铁罐、蛮族露肌或仪仗铠甲。

### 世家少主

**适用对象**：嫡传、贵公子、商会继承人、水/风系雅士。  
**一句话记忆**：浅色大面压住贵气，装饰沿肩腰成线。  
**视觉等级 / 基础结构**：惊艳华贵但可行走；修长 A 形。浅色交领中衣配宽袖外袍，袖口略收，衣长离地一掌，扁平玉扣固定前襟。仅一片窄长薄绸自右肩落至左后腰；窄玉革带收腰，前中开衩至膝，露深一阶直裤与软靴。平整丝绸或细缎，暗纹只在领缘、下摆内圈。  
**必须保留**：离地一掌宽袖外袍；单肩斜落披帛；窄玉革带与前中开衩。  
**辅助 / 可省略**：扁平玉扣；内圈暗纹可省略。  
**防漂移**：不要龙袍、满身金线珠玉、婚服或拖地舞台装。

### 天游祭主

**适用对象**：掌门、仙官、宗族祭主、终局登场。  
**一句话记忆**：大轮廓礼服配一个肩背仪式焦点。  
**视觉等级 / 基础结构**：仪式级华丽；贴腕中衣外是交领大袖礼袍，衣长至足面但不拖地，袖口内收保证手部可见。对称肩披从双肩落至背中，连接一枚扁平宗门徽记；宽织带束腰，前中留腰至踝整齐开片，左右后摆仅延半步。平整低纹理布料；徽记与领缘只共用一种金属线或玉片。  
**必须保留**：可露手大袖礼袍；双肩连背中徽记的肩披；前中开片。  
**辅助 / 可省略**：两枚短垂佩；同色云纹可省略。  
**防漂移**：不要神像全身发光、冕服、数米拖尾、多重披帛或重甲。

## 女装

### 山村采药女

**适用对象**：凡人、采药人、初入修行者。  
**一句话记忆**：短上衣、耐走下装与劳动围腰。  
**视觉等级 / 基础结构**：朴素轻快；浅交领窄袖短襦到腰下，外加及臀短坎肩。过踝窄褶裙内可见方便迈步的裤脚，前方半围腰；小腿两道布带配耐走短靴。洗净棉麻，领缘和围腰只一处撞色细边。  
**必须保留**：窄袖短襦；及臀短坎肩；窄褶裙内露裤脚与绑腿。  
**辅助 / 可省略**：腰侧草药袋；围腰布补可省略。  
**防漂移**：不要蓑衣农妇、华丽仙裙、赤脚精灵或大花绣服。

### 外门短褙

**适用对象**：普通女弟子、山门课业、日常修行。  
**一句话记忆**：直领短褙配稳定长裙的门派基础款。  
**视觉等级 / 基础结构**：朴素清爽；交领窄袖衫外为直领对襟短褙，至大腿中段，腋下高但克制的侧衩，前襟由细腰带压住。高腰六至八褶长裙自然垂至踝上，配软底短靴；低明度门派色、米白内层，领缘一圈细滚边。  
**必须保留**：直领对襟短褙；高腰自然垂落长裙；侧衩露内层。  
**辅助 / 可省略**：小门牌；裙边细边可省略。  
**防漂移**：不要唐风大袖礼裙、现代校服、宫女装或拖地裙。

### 云游女修

**适用对象**：散修、旅者、商队护卫、远行剑修。  
**一句话记忆**：裙裤并用，短斗篷可收纳的远行装。  
**视觉等级 / 基础结构**：实用亮眼；收口窄袖交领上衣，外穿前短后略长的斜襟短袍至大腿中段，宽布带压腰。两片开衩裙覆于窄裤：前后片至膝下，侧面完全露裤腿；肩上仅臀下短斗篷，配护腕、包踝软靴。耐磨哑布，斗篷内衬允许一阶强调色。  
**必须保留**：斜襟短袍；两片开衩裙覆窄裤；臀下短斗篷。  
**辅助 / 可省略**：腰侧扁囊；窄护腕可省略。  
**防漂移**：不要长裙飘带仙子、全身皮衣、现代冒险者或遮体斗篷。

### 灵植花修

**适用对象**：木灵根、灵植师、花圃弟子。  
**一句话记忆**：短半臂、劳动裙与单一种囊。  
**视觉等级 / 基础结构**：轻盈实用；窄袖交领短衫外叠及腰短半臂，半臂袖口略外张但不超肘。高腰前短后长轻褶裙：前至小腿中段，后至踝上，裙内窄裤便于蹲跪；窄围腰只在左侧放一个种囊。平整轻布，叶脉压纹仅在领缘或半臂边。  
**必须保留**：及腰短半臂；前短后长轻褶裙；左侧单一种囊。  
**辅助 / 可省略**：腕部护套；叶脉压纹可省略。  
**防漂移**：不要婚礼花仙、全身花朵、藤蔓缠身或拖地大裙。

### 医女药师

**适用对象**：医修、药师、炼丹学徒、毒术研究者。  
**一句话记忆**：露出手、方便取药的比甲工作裙装。  
**视觉等级 / 基础结构**：实用精致；贴腕交领短衫外罩及膝无袖对襟比甲，腰带压住前襟、两侧开衩。及踝直裙的前中隐藏开片便于跨步；半围腰至大腿，两侧各一扁药囊，配低跟软靴。耐污主布，一圈浅色硬挺包边。  
**必须保留**：贴腕窄袖；及膝无袖对襟比甲；前半围腰与两只薄药囊。  
**辅助 / 可省略**：半指护手；草叶压纹可省略。  
**防漂移**：不要护士制服、宫廷医女、层层纱裙或满挂药瓶。

### 书院阵师

**适用对象**：符修、阵师、书修、高阶弟子。  
**一句话记忆**：长褙子文雅，袖口与开衩仍可走阵掐诀。  
**视觉等级 / 基础结构**：清雅亮眼；窄袖交领长衫外为直领长褙，至小腿中段，肩部自然宽、腕口收窄，腋下高开衩露深一阶内裙。细绦束腰，直落窄褶裙离地一掌，配软靴；平整低光泽布，直领与开衩内侧同色几何织边。  
**必须保留**：直领小腿长褙；宽根收腕袖；高开衩露内裙。  
**辅助 / 可省略**：右腰扁符袋；几何织边可省略。  
**防漂移**：不要大袖仙裙、教师制服、道姑法衣或全身阵图发光。

### 乐修舞者

**适用对象**：音修、幻术师、庆典表演者。  
**一句话记忆**：高腰双层裙负责旋转，一条披帛标出动作路径。  
**视觉等级 / 基础结构**：惊艳；贴身不暴露交领短上衣外罩及腰短半臂。高腰双层长裙，内层略短、外层至踝，裙摆有体积但不拖地；仅一条窄披帛自右上臂绕过背部，末端落左肘后，不遮脸、手、腰。扁平腰封与轻薄舞靴；轻纱只用于外裙与披帛，内层不透。  
**必须保留**：及腰短半臂；高腰双层长裙；右臂绕背至左肘的单条披帛。  
**辅助 / 可省略**：内裙渐变边；腰封扁扣可省略。  
**防漂移**：不要多条飘带遮肢体、全身透明、婚纱或现代舞台礼服。

### 弓骑猎修

**适用对象**：弓手、御兽师、边地猎修、骑乘者。  
**一句话记忆**：平整背部、分片裙甲与左臂护臂的骑猎装。  
**视觉等级 / 基础结构**：战斗实用；贴腕立领短衣至腰下，外叠无袖短马甲，肩背平整，无披帛。四片裙甲覆窄裤：前后至膝、左右略短并分开；左臂由手背至肘下的宽护臂，双腿进长靴。布、压纹皮和少量边缘金属，马甲肩背仅一条低对比兽纹。  
**必须保留**：平整背部短马甲；四片分开裙甲；左臂宽护臂与长靴。  
**辅助 / 可省略**：右腿绑带；兽纹可省略。
