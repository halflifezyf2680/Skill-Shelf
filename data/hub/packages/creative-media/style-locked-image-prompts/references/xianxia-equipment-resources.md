# 仙侠装备资源库

装备指携行、收纳、防护、侦察、采集、治疗、施术、出行和任务工具；不包括直接攻击的武器，亦不包括可自主发动核心神异效果的宝具。由 `SKILL.md` 的统一路由调用：只有职业、任务、旅途或用户要求使其成为可见证据时才选择。默认一件主携行装备加一件职业工具；旅途可再加一件补给装备。所有资源默认男女通用，按服装与活动调整尺寸、材质和挂载侧；调用前检查 `character-resource-routing.md`，不得与服装自带囊袋、腰佩、护具、背部容器或主武器争夺槽位。

## 行旅背囊

**适用对象**：远行修士、散修、护送者、山野角色。  
**一句话记忆**：背部中线的薄而高行囊，不宽过肩。  
**结构 / 功能**：主携行装备。窄长软囊贴背部中线，顶部到肩胛中段，底部不低于腰；两条肩带从肩前落下，在胸前由一段短横带连接。囊体宽度小于双肩，顶部卷口向上，侧面只一只扁水袋或绑带位。粗布、油布或软皮择一，装满但不鼓成球。  
**必须保留**：背部中线位置；不低过腰的窄长囊；向上卷口与双肩带。  
**可省略 / 防漂移**：侧面扁水袋可删；不要现代背包拉链、巨大登山包、披风覆盖整个背囊或背上叠第二个容器。

## 双袋褡裢

**适用对象**：骑乘、采集、商旅、短途行走。  
**一句话记忆**：一条中带连接前后或左右两只扁袋。  
**结构 / 功能**：主携行或补给装备。长布带从一肩斜跨至对侧胯部，前胸保持平整；带体两端各有一只等大的扁方袋，分别落在前侧胯与后侧胯，袋底不低于大腿上段。袋盖朝上，以布扣或木扣闭合；骑乘时两袋可改搭鞍侧，人物身上不同时出现。  
**必须保留**：单条斜跨中带；两只等大扁袋；前后胯部平衡位置。  
**可省略 / 防漂移**：一枚布扣可删；不要双肩背包、夸张邮差包、两袋塞满卷轴武器。

## 腰侧工具囊

**适用对象**：药师、符师、工坊、普通任务角色。  
**一句话记忆**：惯用手反侧腰后的单只扁囊。  
**结构 / 功能**：职业工具。固定在惯用手相反一侧的腰封偏后位置，扁囊宽约一掌半、高约一掌，袋口朝上或朝外，短系带贴腰。囊面只一枚结扣或小标签；不能和同侧重腰佩、禁步、剑鞘叠挂。  
**必须保留**：反侧腰后挂载；单只扁囊；向上/向外开口。  
**可省略 / 防漂移**：小标签可删；不要多层战术袋、巨大皮包、漂浮收纳袋。

## 药筒与折叠药匣

**适用对象**：医修、炼丹师、毒师、随行医者。  
**一句话记忆**：一只硬壳药筒或可折药匣，不把药瓶挂满全身。  
**结构 / 功能**：职业工具。药筒为短圆柱硬壳，竖挂左后腰，筒口朝上，长度到腰下两掌；折叠药匣为两至四格扁方盒，横挂胸前内侧或左腰，合起时薄如掌。二者二选一，外壳为木、漆、竹或暗金属，只有盖面一个简洁药草符号。  
**必须保留**：药筒/折叠药匣二选一；清楚开口/铰链方向；单一主容器。  
**可省略 / 防漂移**：盖面药草标记可删；不要玻璃试管腰带、数十个瓶罐、发光炼金背包。

## 符箓匣 / 经卷筒

**适用对象**：符师、阵师、道修、卷轴施术者。  
**一句话记忆**：保护纸卷的硬壳短匣，背斜挂或腰侧二选一。  
**结构 / 功能**：职业工具。符箓匣是扁长矩形硬盒，斜挂在背后，从右肩到左腰或反向，盒体贴背且长度不超过肩胛至腰的距离；经卷筒是短圆筒，竖挂左腰，盖口向上。二选一，封口用一条短绳或扁扣；表面仅一枚低对比符号。  
**必须保留**：硬壳保护结构；背斜挂/腰侧竖挂二选一；短绳或扁扣封口。  
**可省略 / 防漂移**：表面符号可删；不要把纸符漫天漂浮、不要与书箧或大背囊同背。

## 书箧 / 行箧

**适用对象**：文修、阵师、游学者、信使。  
**一句话记忆**：薄书箱有提梁和侧带，背部只占一个位置。  
**结构 / 功能**：主携行装备。薄矩形书箧高度从肩胛到腰上、宽度小于背宽，硬边清楚；可用双肩短带贴背，或手提一根上方提梁，二选一。正面一枚横向扣，侧面只露一条窄分隔缝，内部书卷不外溢。木、竹或漆面择一。  
**必须保留**：薄矩形硬箱；上方提梁或双肩短带二选一；前面横扣。  
**可省略 / 防漂移**：侧面分隔缝可删；不要现代公文包、厚旅行箱、与背囊/经卷筒叠背。

## 灵植采集篓

**适用对象**：灵植师、采药者、园圃弟子、山野旅者。  
**一句话记忆**：开口向上的轻篓，留一个短剪或小铲位。  
**结构 / 功能**：主携行或职业工具。背篓置于背部中线，篓口高于肩胛、底部到腰；侧篓以宽带从一肩斜挂，落在对侧胯外，二者二选一。篓口始终向上，编织结构清楚，内部只露少量叶片或布包；篓侧可插一把短剪或小铲，但不能两者都有。  
**必须保留**：背篓/侧篓二选一；向上开口；单一短剪或小铲位。  
**可省略 / 防漂移**：篓内少量叶片可删；不要巨型竹篓、满溢奇花、篓中放灵兽或武器。

## 御兽携具

**适用对象**：御兽师、猎修、巡山者。  
**一句话记忆**：一件控制或照料工具，不把灵兽本身当装备。  
**结构 / 功能**：职业工具。兽哨为拇指长骨/木哨，挂在胸前短绳；折叠食囊是扁布包，挂在反侧腰后；短牵绳卷成手掌大的圈，扣在腰带侧后。三选一，若用户要求照料与控制可同时选两件，但不得再叠工具囊。材质朴素，不发出大面积光效。  
**必须保留**：兽哨/食囊/短牵绳的明确单件；胸前或腰侧固定点；小体积。  
**可省略 / 防漂移**：一枚小扣可删；不要把灵兽画成背包、长鞭、金属链网或满腰宠物用品。

## 照明与引路具

**适用对象**：夜行、地宫、远行、探查场景。  
**一句话记忆**：小灯、灯匣或罗盘三选一，光只照工具周围。  
**结构 / 功能**：任务工具。手提小灯由短柄和封闭灯罩组成，垂在手侧但不超过膝；腰后灯匣为掌大扁盒，开口朝上；罗盘为掌大圆盘，以短绳系于胸前或腰侧。三选一。灯具只在灯芯/窗口发出局部柔光，罗盘针或纹路只微亮一处。  
**必须保留**：小灯/灯匣/罗盘三选一；明确握持或挂载；局部功能微光。  
**可省略 / 防漂移**：灯罩花纹可删；不要巨型灯笼、全身照明光环、漂浮光球或武器化法器。

## 防护护具

**适用对象**：弓手、攀登者、近战任务、风沙雨雪场景。  
**一句话记忆**：按动作选一至两件软护具，而不是拼成盔甲。  
**结构 / 功能**：动作防护。射鞴为惯用手反侧前臂的皮/布护臂，腕至肘下；攀登护掌只覆盖掌心与拇指根；护膝为裤外一对薄垫，不延及胫；面巾是颈部向上拉起的窄布，不遮头顶。默认选一件，极端环境最多两件，皆以绑带贴合身体。  
**必须保留**：明确动作对应的单件；贴合关节/前臂；软材质与短绑带。  
**可省略 / 防漂移**：一枚小护边可删；不要完整盔甲、现代战术护具、双臂双腿全覆盖。

## 水具与净具

**适用对象**：行旅、医修、祭祀、沙漠或山路场景。  
**一句话记忆**：扁水囊、短净瓶、折叠杯只取一件。  
**结构 / 功能**：补给工具。扁水囊挂在腰侧偏后，囊口向上且不低于大腿上段；短净瓶为掌长带盖小瓶，挂在腰前内侧或手持；折叠杯收成扁圆片，系在腰带侧。三选一；皮、漆木、陶或金属择一，若有灵性仅在瓶口一圈微光标明净化功能。  
**必须保留**：水囊/净瓶/折叠杯三选一；明确开口方向；掌大到大腿上段的合理尺寸。  
**可省略 / 防漂移**：瓶口细纹可删；不要巨型葫芦、悬浮水球、满身水瓶或当作法宝喷泉。

## 宗门任务具

**适用对象**：执事、巡查、信使、领任务角色。  
**一句话记忆**：令牌套、封信筒、任务卷轴匣三选一。  
**结构 / 功能**：任务工具。令牌套为腰侧小扁套，露出一角身份牌；封信筒为掌长细圆筒，竖挂胸前或腰侧，封蜡端朝上；任务卷轴匣为短扁盒，固定在腰后，开口向侧。三选一，主表面仅一个宗门标志，不能与佩绶令绶重复使用。  
**必须保留**：三选一的明确器型；胸前/腰侧/腰后固定点；单一宗门标志。  
**可省略 / 防漂移**：封蜡或套边可删；不要公文包、军功勋章、武器卷轴或多枚令牌堆叠。
