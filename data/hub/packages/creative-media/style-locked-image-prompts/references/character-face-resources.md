# 原画人物面部资源库

只在 `SKILL.md` 的面部路由触发时读取。面部是角色连续性资源，不进入 Style lock。先锁定脸型，再锁定眉眼关系，最后只设一个主识别点；不要用真人毛孔、法令纹、全脸油光、统一尖下巴或过度幼态化替代设计。

## 脸型

| 调用名 | 可见结构 | 适配与防漂移 |
| --- | --- | --- |
| 柔长椭圆脸 | 额头与颧区平顺，向窄圆下巴收束，面中略长 | 配低弧眉、狭长/杏眼；不要针状下巴 |
| 短椭圆脸 | 面长较短，颊部饱满，颌角圆润 | 配平直眉、清透杏眼；避免眼大鼻口过小的过度幼态 |
| 窄菱形脸 | 颧区最宽，太阳穴与下颌较窄，利落收束 | 配低眉峰、狭长眼；颧骨不可病态突兀 |
| 方圆脸 | 额宽接近颧宽，颌角有厚度但转角圆钝 | 配直眉、横向眼型；不可被统一削成尖下巴 |
| 倒三角脸 | 额部较宽，颧部向下快速收窄，下巴短而明确 | 配轻挑眉、宽眼裂；额头不可过宽、下巴不可过细 |
| 长方脸 | 额、颧、下颌宽度接近，垂直长度明显 | 配横向眉眼；不用深皱纹或重阴影强行显老 |

## 五官调用项

按“眉 → 眼 → 鼻 → 唇”的顺序写入；只在局部模式中读取对应行。

| 部位 | 调用名 | 可执行结构 |
| --- | --- | --- |
| 眉 | 平直眉 | 眉头至眉峰平稳，尾部轻收，不压上眼睑 |
| 眉 | 低弧眉 | 柔和弧线，眉峰不高，眉尾自然落点 |
| 眉 | 轻挑眉 | 后段眉峰，眉尾略上收 |
| 眼 | 狭长内收眼 | 眼裂横向拉长，内眼角收敛，外眼角微扬 |
| 眼 | 清透杏眼 | 上下眼睑弧度均衡，虹膜可见充分，外眼角平稳 |
| 眼 | 平展凤眼 | 内眼角略低、外眼角微扬，虹膜可见适中 |
| 眼 | 下垂圆眼 | 外眼角轻落，眼裂圆润，下睑结构清楚 |
| 鼻 | 清直鼻 | 鼻根至鼻梁平顺，鼻尖小而有体积，鼻翼收敛 |
| 鼻 | 短直鼻 | 鼻部较短，鼻尖圆钝，鼻翼边界柔和 |
| 鼻 | 稳厚鼻 | 鼻根有支撑，鼻梁宽度适中，鼻尖与鼻翼体积清楚 |
| 唇 | 薄直唇 | 上下唇厚度接近，唇线平缓 |
| 唇 | 清晰唇峰 | 上唇中央柔和唇峰，下唇饱满但不镜面反光 |
| 唇 | 圆钝短唇 | 唇幅不宽，边缘柔和，口角平稳 |

## 面部设计包

每次完整设计只选一个包，可再做一项局部微调。

| 调用名 | 组合 | 主识别点 |
| --- | --- | --- |
| 清雅主角型 | 柔长椭圆脸、低弧眉、狭长/清透杏眼、清直鼻、薄至中等唇 | 干净狭长眼型 |
| 灵动少年型 | 短椭圆脸、平直眉、清透杏眼、短直鼻、圆钝短唇 | 清透眼神 |
| 冷感谋士型 | 窄菱形脸、轻挑眉、狭长内收眼、清直鼻、薄直唇 | 略上收的眼尾 |
| 英气行动型 | 方圆脸、平直眉、平展凤眼、稳厚鼻、简洁唇 | 稳定眉眼方向 |
| 华丽贵胄型 | 倒三角脸、轻挑眉、宽眼裂、清直鼻、清晰唇峰 | 眼型或唇色二选一强调 |
| 沉稳长者型 | 长方脸、平直眉、横向眼型、平顺长鼻、低饱和唇色 | 面部长度与平稳轮廓 |

## 表情、肤质与连续性护栏

- 表情一次最多改变眉毛方向、眼睑开合、口角幅度中的两项，保留固有眼型和脸型。
- 肤质用干净设计化色面，在眉弓下、鼻侧、颧骨、唇下与下颌保留选择性转折；高光最多服务眼神光和鼻尖/唇峰之一。
- 妆面必须有身份或场合理由；不默认浓妆。水墨、钢笔和黑白线稿不写肤质、妆色与细密高光。
- 发际线、刘海开合与鬓发结构是脸部连续性锚点；与脸型一同固定，不得随场景无端改变。
