# 仙侠独立装饰品资源库

本库仅收录发型资源之外的身体与服装佩饰，不含头饰、武器、宝具。由 `SKILL.md` 的统一路由调用：局部模式仅响应明确佩饰要求；完整模式也只有在身份、场合或叙事需要时才选择，不能为凑“全套”自动添加。资源按传统仙侠世界的默认性别佩戴习惯划分：男用专属与女用专属不可自动互换；仅在用户明确要求反差设定、跨性别穿搭、特定门派制服或指定某件时覆写。默认一项主装饰；确有可读价值时再加一项辅装饰，礼仪级最多三项并分布在不同高度。调用前检查 `character-resource-routing.md` 的槽位表；服装自带件优先占位。

## 男用专属

### 右拇指扳指

**适用对象**：弓修、世家男性、武修男性。  
**一句话记忆**：右手拇指的厚壁实用扳指。  
**结构 / 视觉等级**：实用亮眼。仅戴在右手拇指，形体为短圆筒或微斜口厚环，外露高度不超过拇指第一节；玉、骨、木或暗金属择一，不镶大宝石。射箭时扳指贴近弓弦侧，静态时仍保持简洁。  
**必须保留**：右手拇指位置；厚壁短筒轮廓；单一材质。  
**可省略 / 防漂移**：一圈极细刻纹可删；不要戴满十指、不要现代戒指堆叠、不要把扳指画到食指。

### 双组玉佩

**适用对象**：文修男性、世家男性、正式访客。  
**一句话记忆**：左右腰各一组短玉佩，端正而不拖地。  
**结构 / 视觉等级**：清雅正式。腰带左右各挂一组同材质短佩，每组由一块横向小珩、一枚中部扁佩与一枚末端小坠组成，长度到大腿上段，左右对称但不碰膝。以丝绦系在腰封外侧，玉色温润、绦色低对比。  
**必须保留**：左右腰对称两组；三段式短佩结构；大腿上段长度。  
**可省略 / 防漂移**：小坠边缘纹可删；不要一侧单挂、腰下长串、走路战斗时满身碰撞。

### 蹀躞带

**适用对象**：执事男性、游侠男性、武职或工坊男性。  
**一句话记忆**：腰带本体带功能挂点，不是长流苏腰链。  
**结构 / 视觉等级**：实用职业型。宽革带或硬挺织带绕腰一周，前中一个扁平带扣；左右腰各有一至两个短小带环，分别挂扁囊、短匙套或令牌套，挂物均止于腰下两掌。金属只出现于扣与带环，主材为皮革或织带。  
**必须保留**：宽带本体；前中扁平带扣；腰侧短带环与小挂件。  
**可省略 / 防漂移**：一只小匙套可删；不要西式战术腰带、夸张工具墙、长垂链。

### 佩绶令绶

**适用对象**：宗门执事男性、官职男性、礼仪男性。  
**一句话记忆**：从腰封垂下的窄绶带与一枚身份牌。  
**结构 / 视觉等级**：正式。单条窄织绶固定在右腰或左腰，不跨过腹部；绶带直垂至大腿中段，末端挂一枚扁平令牌或印形佩。绶带有一圈低对比织边，令牌只一个宗门符号，不带流苏。  
**必须保留**：单侧窄绶；大腿中段长度；末端单枚扁令牌。  
**可省略 / 防漂移**：织边可删；不要双侧长绶、军功勋章墙、跨胸绶带。

### 护腕玉扣

**适用对象**：文武世家男性、剑修男性、礼服男性。  
**一句话记忆**：袖口或护腕上的一枚可见玉扣。  
**结构 / 视觉等级**：低调精致。只在一侧手腕外侧设置短护腕或加宽袖口，其上嵌一枚扁圆或椭圆玉扣；护腕宽度不超过手腕至前臂三分之一，玉扣与服装主色低对比。它是衣物闭合件而非完整手镯。  
**必须保留**：单侧腕部；短护腕/加宽袖口；一枚扁玉扣。  
**可省略 / 防漂移**：玉扣刻纹可删；不要双臂重甲、宽大金镯或多枚腕饰。

## 女用专属

### 成对耳珰

**适用对象**：世家女性、礼宴女性、成年女修。  
**一句话记忆**：双耳同形、小而清楚的短垂耳珰。  
**结构 / 视觉等级**：亮眼。左右耳垂各一枚同形耳珰：耳钩或耳珠下只垂一颗玉珠、金属叶片或小水滴，垂长止于下颌线以上。材质一主一辅，例如银配玉、金配珍珠，不再叠第三种。  
**必须保留**：双耳对称；短垂至下颌线上方；单一坠体。  
**可省略 / 防漂移**：耳钩花纹可删；不要耳坠垂肩、两耳不同形、耳链绕脸。

### 压襟

**适用对象**：女修、贵女、文修女性、正式常服。  
**一句话记忆**：固定在交领交会处的一枚扁平主坠。  
**结构 / 视觉等级**：清雅亮眼。压襟固定在交领或对襟的胸前交会点，主体是一个扁平圆、叶、锁或几何形坠，下面可接一段短绦与一枚小玉珠，总长度不超过胸骨下缘。压襟贴衣，不跨过肩，不悬到腰部。  
**必须保留**：胸前交会点挂载；扁平主体；短绦止于胸骨下缘。  
**可省略 / 防漂移**：末端小珠可删；不要长项链、胸口成排珠串或巨型胸针。

### 禁步

**适用对象**：礼仪女性、世家贵女、静态宴会角色。  
**一句话记忆**：腰侧垂至膝上的压裙组佩，只适合慢步。  
**结构 / 视觉等级**：华丽礼仪级。固定在一侧腰封，主绦垂到膝上，沿线依次有一块扁玉牌、两至三枚小型片佩与最下方短坠；总件数三至五件，重量和长度压住裙侧。玉、珠和丝绦只各一类，不加入长流苏。  
**必须保留**：单侧腰封挂载；三至五件竖向组佩；末端止于膝上。  
**可省略 / 防漂移**：中部一枚小片佩可删；不要战斗骑乘使用、不要两侧对称、不要拖地珠帘。

### 腕镯/手串

**适用对象**：女修、魅修、贵女、日常轻饰。  
**一句话记忆**：一只手腕的一件细饰，避免双手堆满。  
**结构 / 视觉等级**：低调至亮眼。只选左或右手腕佩戴：可是一只实心细玉镯、三至七颗等大的珠串，或一条细金属环，三选一。宽度不超过腕部三分之一；若衣袖遮住腕部，则只露出一小段边缘。  
**必须保留**：单手腕；一件单体腕饰；细窄比例。  
**可省略 / 防漂移**：一枚小隔珠可删；不要双臂多镯、手表、现代夸张串珠。

### 上臂臂钏

**适用对象**：战舞女性、魅修女性、贵女夏装、成年女性。  
**一句话记忆**：上臂中段的单侧环饰，不下滑到手腕。  
**结构 / 视觉等级**：亮眼至华丽。只戴在一侧上臂中段，袖口外或露臂区域；一只开口硬环或三圈以内的同材质细环，内径贴合手臂，最宽不超过两指。金、银、玉或漆木择一，环面仅一枚小型花叶/云纹焦点。  
**必须保留**：单侧上臂中段；一环或至多三圈；不延至手腕。  
**可省略 / 防漂移**：环面小纹可删；不要双臂十余圈、链条垂到肘部、战甲护臂。

### 女式香囊与裙侧小佩

**适用对象**：闺阁女性、药修女性、日常礼服女性。  
**一句话记忆**：腰侧短绦上的小香囊或扁佩，轻而不撞裙。  
**结构 / 视觉等级**：低调精致。固定在一侧腰带，选圆角小香囊或一枚扁小佩，二选一；短绦长度到大腿上段，主体不超过手掌大。香囊采用织物与一枚结扣，扁佩采用玉/木/金属一种材质；不和禁步同侧同用。  
**必须保留**：单侧腰挂；手掌大小主体；大腿上段短绦。  
**可省略 / 防漂移**：一颗末端小珠可删；不要工具包、长流苏、双侧满挂或与禁步叠加。

## 男女通用

### 护符颈牌

**适用对象**：医修、符师、宗门身份、需要护身意象的角色。  
**一句话记忆**：贴在胸骨上方的一枚扁平护符牌。  
**结构 / 视觉等级**：实用清楚。细绳、窄革绳或短金属链择一，围颈长度停在锁骨之间；中央只一枚竖向扁牌，大小约两指宽，刻一个简洁符号。应露在低领内层或衣领外侧，不能横跨衣襟。  
**必须保留**：锁骨间短链；中央单枚竖向扁牌；一个简洁符号。  
**可省略 / 防漂移**：牌边细框可删；不要十字架式宗教符号、长念珠、多层项链。

### 短项坠

**适用对象**：低领常服、轻礼服、日常角色。  
**一句话记忆**：锁骨中央的一条细链配一个小坠。  
**结构 / 视觉等级**：低调。细链或丝绳贴颈，长度到锁骨中央；坠体为小圆片、短玉管、叶片或水滴，四选一，大小不超过拇指第一节。只在衣领较低或领口清楚时使用。  
**必须保留**：锁骨中央位置；单条细链；一个小坠。  
**可省略 / 防漂移**：坠体微纹可删；不要长至胸下、粗金链或多层叠戴。

### 单玉腰佩

**适用对象**：文修、普通贵族、日常仙侠角色。  
**一句话记忆**：一侧腰封一块玉佩，短而稳。  
**结构 / 视觉等级**：清雅。左或右腰二选一，短绦从腰封下垂至大腿上段，末端只挂一枚扁圆、半月或叶形玉佩。绦结贴近腰封，玉佩正面一处浅刻纹，走路时不碰膝。  
**必须保留**：单侧腰封；单枚扁玉佩；大腿上段长度。  
**可省略 / 防漂移**：浅刻纹可删；不要同时变成双组玉佩、禁步或长流苏。

### 工具腰坠

**适用对象**：药师、符师、旅者、工坊角色。  
**一句话记忆**：腰侧后方的一只扁囊或令牌套。  
**结构 / 视觉等级**：实用。固定在惯用手相反一侧的腰封偏后位置，只选一只扁平小囊、卷轴套或令牌套；主体到腰下两掌，开口朝上或朝侧，系带短且贴身。材质与腰封协调，不发光。  
**必须保留**：腰侧偏后位置；一只扁平容器；短贴身系带。  
**可省略 / 防漂移**：一枚封口结可删；不要背包、满腰工具、武器鞘或魔法漂浮包。

### 肩侧别饰

**适用对象**：世家、仪式、披帛或披风固定处。  
**一句话记忆**：一侧肩部或披帛根部的一枚扁平别饰。  
**结构 / 视觉等级**：亮眼。只在左或右肩选择一处，固定衣领外缘、披帛根部或短披风结点；主体为扁平圆、花、叶或家徽，不超过掌心三分之一。材质单一，别针贴布，不挂长坠。  
**必须保留**：单侧肩部挂载；扁平小型轮廓；无长坠。  
**可省略 / 防漂移**：边缘细纹可删；不要双肩勋章、巨大胸甲徽章或现代胸针组合。

### 单枚指环

**适用对象**：术士、贵族、日常角色。  
**一句话记忆**：一根手指上一枚低调主环。  
**结构 / 视觉等级**：低调。戴于左或右手的食指、中指或无名指，三选一；细环、窄面戒或小印面戒三选一，面宽不超过指节三分之一。玉、银、金属或木质择一；施法时不要把戒面画成夸张魔法宝石。  
**必须保留**：单根手指；一枚指环；细窄或小印面。  
**可省略 / 防漂移**：一枚极小刻纹可删；不要多指戒、拳套、巨大宝石或与男用扳指混同。
