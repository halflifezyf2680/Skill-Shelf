# Responsive Layout

## Desktop

- Use 12-column or two-column grids.
- Put title, main structure, and evidence/result areas in one viewport when possible.
- Use max-width containers around 1440px to 1680px for dense tools.

## Tablet

- Collapse 3-5 column flows into 2 columns.
- Keep arrows as labels or vertical connectors.

## Mobile

- Collapse to single-column sections.
- Keep code labels wrap-safe with `overflow-wrap: anywhere`.
- Avoid hover-only content.
- Make chips and buttons at least 40px high.

## Checks

- No text overflow.
- No overlapping fixed headers.
- No horizontal scroll except intentional code panes.
- Primary action and current state remain visible.
