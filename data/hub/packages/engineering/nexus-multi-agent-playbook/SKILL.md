# NEXUS 多智能体编排手册

把独立的 AI 专家智能体协调成一条有质量门禁的流水线。完整体系见 references/：

| 文档 | 内容 |
|---|---|
| nexus-strategy.md | 完整运营手册：运营模型、协调矩阵、交接协议、质量门禁、风险管理 |
| phase-0-discovery.md ~ phase-6-operate.md | 7 个阶段手册：情报发现 → 策略架构 → 基础脚手架 → 构建迭代 → 质量加固 → 上线增长 → 运营收敛 |
| scenario-startup-mvp.md | 场景剧本：创业 MVP（4-6 周，18-22 智能体） |
| scenario-enterprise-feature.md | 场景剧本：企业级功能开发 |
| scenario-incident-response.md | 场景剧本：事故响应 |
| scenario-marketing-campaign.md | 场景剧本：营销活动 |
| agent-activation-prompts.md | 各智能体的即用激活提示词模板 |
| handoff-templates.md | 智能体间标准化交接模板 |

三种模式：NEXUS-Full（完整产品 12-24 周）/ NEXUS-Sprint（功能或 MVP 2-6 周）/ NEXUS-Micro（单任务 1-5 天）。
